Hostel Booking System

The Hostel Booking System is a digital platform designed to help students find available hostel accommodation and manage their bookings more easily.

Project Purpose

The system is designed to make the hostel booking process easier by allowing students to view hostel information, check availability, and make bookings through a digital platform.

Technologies Used

  • Flutter
  • Dart
  • Java
  • Spring Boot
  • Angular

System Components

The mobile application is developed using Flutter and Dart. The backend uses Java and Spring Boot, while Angular is used for the web interface.

What I Learned

Through this project, I am gaining practical experience in mobile development, backend development, web development, APIs, databases, and connecting different parts of a software system.
